Specifica OpenAPI ↗

Indirizzo base

Dalle app su questo PC non serve la chiave. Per altri computer e server attiva l'accesso dalla rete nelle impostazioni e usa una chiave API.

Chiavi API

Una per ogni sistema che usa ideax: vedi chi lo usa e puoi bloccarne uno senza toccare gli altri.

Webhook

Aggiungi callback_url alla richiesta: ideax risponde subito e, quando il lavoro è finito, chiama quell'indirizzo con il risultato. Ogni chiamata è firmata in X-Ideax-Signature (HMAC-SHA256 del corpo con il segreto qui sotto), così il vostro sistema sa che arriva davvero da ideax.

Esempi pronti

Copiali nei vostri sistemi: l'indirizzo è già quello giusto.

Endpoint disponibili

MetodoPercorsoA cosa serve
POST/v1/generateCrea un lavoro. JSON o multipart con file. Campi: prompt, e facoltativi task, model, params, attachments, callback_url, metadata, wait, inline
GET/v1/jobs/:idStato, avanzamento e risultati di un lavoro
POST/v1/jobs/:id/cancelAnnulla un lavoro
GET/v1/creationsArchivio delle creazioni, con type, q (ricerca), limit, offset
GET / DELETE/v1/creations/:idUna creazione (con ?inline=true i file in base64) o la sua eliminazione
GET/v1/modelsModelli disponibili e compiti
GET/v1/healthStato del servizio, per il monitoraggio (senza chiave)
POST/v1/images/generationsFormato compatibile OpenAI
